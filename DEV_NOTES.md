# Dev Notes

## Slider - Routes

1. Контекст: блок выбора маршрута в мобильной и планшетной версиях.

   Компоненты:
   - `components/MobilePage.vue`
   - `components/TabletPage.vue`

2. Реализация: используем `Swiper` / `SwiperSlide` из `swiper/vue`.

   Основные параметры:
   - `slidesPerView: 1`
   - `speed: 520`
   - `autoHeight: false`
   - `allowTouchMove: true`
   - `grabCursor: true`
   - `observer: true`
   - `observeParents: true`

   Навигация кастомная: стрелки и точки остаются элементами макета, но переключают слайд через `swiper.slideTo()`.

3. Анимация перехода:

   При смене слайда используется горизонтальный Swiper-переход `520ms`.

   Карточка дополнительно анимируется CSS:
   - активный слайд: `opacity: 1`, `scale(1)`, `translateY(0)`
   - соседние слайды: `opacity: 0.42`, `scale(0.94)`, небольшой `translateX`
   - easing: `cubic-bezier(0.22, 1, 0.36, 1)`

   Эффект: активная карточка мягко проявляется и увеличивается, соседняя уходит приглушенной.

4. Высота и отсутствие скачков:

   `autoHeight` выключен, чтобы секция не меняла высоту при переходе между маршрутами.

   Планшет:
   - контейнер Swiper фиксирован по высоте: `466px`
   - карточка занимает `height: 100%`
   - короткий контент распределяется внутри карточки без изменения высоты блока

   Мобильная версия:
   - контейнер Swiper фиксирован по высоте: `515px`
   - длинные карточки скроллятся внутри карточки
   - скроллбар виден только при переполнении по высоте

   Планшетная версия:
   - при переполнении контента белая карточка скроллится внутри фиксированной высоты
   - скроллбар тонкий, в цветовой системе карточки

5. Состояние и синхронизация:

   Активный слайд синхронизируется с `selectedRouteIndex`.

   Смена возможна через:
   - свайп
   - стрелки
   - точки

   На старте используется guard `isMobileSwiperReady` / `isTabletSwiperReady`, чтобы Swiper не сбрасывал активный маршрут во время первичной инициализации.

6. Доступность:

   Стрелки имеют `aria-label`.
   Точки имеют `aria-current` для активного маршрута.
   В мобильной версии у неактивных слайдов выставляется `aria-hidden`.

7. Важное для верстки:

   Не включать `autoHeight`, иначе при смене маршрутов будет перепад высот.
   Не заменять кастомные точки/стрелки на стандартные Swiper controls без отдельного согласования с макетом.
   При добавлении более длинного текста проверять мобильную и планшетную карточку: текст должен оставаться внутри фиксированной высоты и скроллиться внутри карточки.

## Desktop - Route Card

1. Контекст: десктопная карточка маршрута `.route-card` в блоке `#routes`.

2. Поведение при переполнении:

   Если контент не помещается по высоте, карточка скроллится внутри себя.

   Параметры:
   - `overflow-y: auto`
   - `overflow-x: hidden`
   - `min-height: 0` для корректного скролла внутри flex-контейнера
   - тонкий скроллбар в цветовой системе карточки

3. Важное для верстки:

   Не возвращать `overflow: hidden` на `.route-card`, иначе длинные маршруты будут обрезаться.
   Если меняется высота блока маршрутов, проверять, что кнопка `Узнать подробнее` остается доступной через внутренний скролл карточки.
